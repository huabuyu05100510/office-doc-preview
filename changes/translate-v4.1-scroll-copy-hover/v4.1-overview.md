## 关键技术点

### 1. textDir fallback（v4.1.1）

```js
// 旧：p.text || '' → 真实数据中 p.text 不存在 → ''
// 新：p.text || readPageTextFromTextDir(task, p.page) → 真实文本
function readPageTextFromTextDir(task, pageNum) {
  const file = path.join(task.textDir, `page-${String(pageNum).padStart(3, '0')}.html`)
  const html = fs.readFileSync(file, 'utf-8')
  const re = /<span[^>]*>([^<]*)<\/span>/g
  const parts = []
  let m
  while ((m = re.exec(html)) !== null) {
    if (m[1]) parts.push(decodeHtmlEntities(m[1]))
  }
  return parts.join('')  // 顺序拼接，与 charMap 字符位置严格对应
}
```

### 2. HTML 实体解码（v4.1.2）

```js
function decodeHtmlEntities(s) {
  return String(s)
    .replace(/&lt;/g, '<')
    .replace(/&gt;/g, '>')
    .replace(/&quot;/g, '"')
    .replace(/&#39;/g, "'")
    .replace(/&amp;/g, '&')  // &amp; 最后处理（避免双重解码）
}
```

**为什么需要**：PDFium 提的 run.str 是原始字符（含 `<`），textDir HTML 是转义后的（含 `&lt;`）。两者必须对齐，否则 `indexOf` 失败 → 降级 runToSpan。

### 3. 默认 zoom 自适应（v4.1.3）

```ts
const computeFitWidth = useCallback(() => {
  const containerW = containerRef.current?.clientWidth
  const sampleW = pages[0]?.pageW || 991
  const rowW = sampleW * 2 + 19  // 左 + divider + 右 + row padding
  return Math.max(0.4, Math.min(1.0, +((containerW * 0.95) / rowW).toFixed(2)))
}, [pages])
```

### 4. 复制联动（v4.1.4）— 行业缺口

```ts
const copyBilingual = useCallback(async () => {
  const html = `<table border="1">${rows}</table>`
  const plain = pages.map(p => `${p.sourceText}\t${p.targetText}`).join('\n')
  await navigator.clipboard.write([
    new ClipboardItem({
      'text/html': new Blob([html], { type: 'text/html' }),
      'text/plain': new Blob([plain], { type: 'text/plain' }),

}, [result])
```

**粘到 Word 完美**：HTML 格式自动变表格，纯文本制表符变 Excel 列。
