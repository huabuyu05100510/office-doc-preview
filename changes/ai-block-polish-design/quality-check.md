## 1.4 关键交互流

1. **输入** → 自动加载示例文本（已实现）→ contentEditable 富文本
2. **点击"开始校对"** → POST `/api/inspect/quality-check` → loading 旋转 + token 渐入（每个 token 错 200ms 间隔入场，已有 `.xf-token.error` 样式）
3. **hover 联动**：token hover → 80ms debounce → 右侧 error card scrollIntoView；card hover → 80ms debounce → token 高亮（**已实现**）
4. **Accept / 改写 / 忽略**：
   - Accept → 红色 token 渐隐（300ms）→ "已应用" Toast（含 5s Undo）
   - 改写 → 弹出 AI 改写对比浮层 → 选"全部接受 / 单句接受 / 拒绝"
   - 忽略 → token 渐隐 + 加 `.xf-token.ignored`（灰色删除线）
5. **改正后双栏** → 一键复制（已实现）
6. **键盘快捷键**：`⌘+Enter` 开始校对 / `↑↓` 翻错误 / `Tab` 接受 / `Esc` 关闭对比

## 2.4 关键交互流

1. **上传** → drag/drop 或点击 → 上传到 `/api/upload` → 后端转 PDF（如 docx → soffice → PDF）
2. **PDF.js 渲染** → 复用现有 `pdfium-text-layer` 或 pdf.js → 文字层定位

## 8.3 跨子模式共享建议

1. **统一错误框架**：7 子模式都使用 `token + bbox + 等级 + 置信度 + 法规/规则引用` 同一数据 schema，复用 `.xf-token` + `.xf-bbox` + `.xf-bubble` 三套样式
2. **统一顶部工具条**：7 子模式共享 `xf-toolbar` + `[🚨 开始] [⚙ 配置] [💾 导出]`
3. **统一观测 Header**：每个 API 都加 `X-{Mode}-Engine / Ms / Hits / Hit-Detail`，前端在 toolbar 显示
4. **统一深色模式**：7 子模式共享同一套语义 token + 风险 4 档色（已在 P1.A semantic tokens 落地）
5. **统一 ⌘K 集成**：每个子模式的关键动作（开始审核 / 导出报告 / 切换行业）注册到 `palette/actions` source（已在 P2.B 落地）
6. **统一 AI 改写组件**：text 模式的 AI 改写对比浮层可复用到所有子模式（"改写"按钮）
7. **统一时间轴**：audio / video 子模式复用 VoicePage `voice-timeline`（三色版）

## 8.4 关键风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 合规词库涉政敏感 | 法律风险 | 内置词库用公开词典（百度/讯飞）+ 显式免责声明 + 不存储用户文本 |
| 人脸识别 / 声纹库隐私 | GDPR / 个人信息保护法 | 默认不开启 + 显式勾选 + 数据本地化 |
| ffmpeg 抽帧慢 | 视频审核体验差 | 后台异步 + 进度推送（SSE/WebSocket）|
| 7 子模式 UI 分散 | 用户认知负担 | 共享 xf-toolbar + xf-submenu（已实现）+ 统一 hero 文案 |
| 误判投诉 | 品牌风险 | 申诉通道 + 人工复审工作台 + 7 天回执 |

## 8.5 一句话总结

> **text 模式已基本完成** → **下周优先交付 text-compliance + image-compliance**（复用现有 token / SVG 框架，ROI 最高）→ **两周内交付 doc-compliance + doc + audio**（与现有 doc / VoicePage 联动）→ **月底前交付 video**（复杂度最高，留作压轴）。
