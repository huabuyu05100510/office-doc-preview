## 1. realtime（实时翻译）— 词级对齐 + 段落对照 + 标注反馈 + 500ms debounce

### 1.1 业界最佳实践

**DeepL Translator / DeepL Write**（行业"质感天花板"）
- 杀手锏：左侧原文 + 右侧译文，词级着色（hover 词/短语 → 同色高亮对应译文），鼠标悬浮即时浮出词典卡片（词性、变形、例句）。
- 交互创新：Ctrl+Enter 不打断当前编辑；`T` 翻译、`Ctrl+Shift+X` 切源/译；术语表 (Glossary) 集成（Pro 计划），支持 CSV/TSV 导入，术语在两端着色完全一致；`Alt` 键按"段"高亮（避免误选词）。
- 视觉设计：极简白底（#FFFFFF）+ 蓝灰文字（#0F1B2D）+ DeepL 蓝（#0F2B96）作为唯一品牌色；译文蓝色 hover 涟漪（120ms ease-out）；字体 Inter / Source Sans，字重 Source Code 14-18px。
- 技术亮点：流式 token 输出 + 词对齐 Myers diff；端到端增量延迟 150-300ms（取决于网络）。

**Google Translate**（"全平台覆盖之王"）
- 杀手锏：增量实时翻译（敲第一个字母开始 100ms 增量输出）；圆角 28px 输入框（Material 3 风格）；Conversation Mode 双向麦克风。
- 视觉设计：左源 / 右译，色板 Material You 动态取色；词级 hover 高亮黄色（#FDD663，translate.google.com 风格）；语言对选择器顶部对齐；右下角浮动"提供反馈"小图标。
- 交互创新：最近翻译历史（7 天）→ 左侧 Drawer；`Ctrl+Alt+Z` 撤销上段替换；划词即译（桌面端插件）；`Alt+←/→` 切换历史版本。
- 2024-2025 增量：Gemini 1.5 Pro 驱动，新增"Listen" 按钮朗读发音（多口音切换：US/UK/AU/IN）。

**Reverso Context**（语境例句王）
- 杀手锏：每词下挂真实语料例句（电影/新闻/对话），点击展开多语对照。
- 视觉设计：单栏源 + 译文 inline 灰底框；例句带左右箭头（←/→）翻页；橙色 #FF6B35 配色。
- 交互：单击词即查，无需 Ctrl；支持 Firefox/Chrome/Safari 插件；离线包可下载（旅游场景）。

**Linguee**（双语句对库）
- 杀手锏：把"双语对齐"做到极致——左侧整段 + 右侧整段，词组蓝色下划线（双语短语锚点），点击即跳到独立对齐详情页。
- 视觉：白底+深灰字+蓝色超链；分页式呈现（页脚 ←/→ 翻页）。
- 数据：词条从欧盟法 EUR-Lex 平行语料 + Web 爬取（多领域）。

**沉浸式翻译**（中文用户最常用，2024 年日活 >400 万）
- 杀手锏：双栏并排（按段落分）；支持 PDF / EPUB / 视频字幕 / 任意网页；移动端 AppleBooks 直接翻译。
- 视觉：双语并排默认左源右译，译文字号/字体可调；右侧浮窗"显示原文"复选框；术语库自建（用户输入中文 → 目标语言强制替换）。
- 交互：鼠标悬停段落 → 临时显示翻译；Ctrl+Shift+A 切换双语/单语；`Alt+Z` 重新生成译文。
- 商业模式：基础免费（DeepL/Google/OpenAI 任选），Pro 18 元/月（增加 OpenAI GPT-4o / Claude 3.5 接入）。

**Mate Translate / 沙拉查词**
- 杀手锏：全平台（macOS/iOS/Chrome/Safari/Firefox）；离线翻译（iOS 15 之后苹果翻译框架）。
- 视觉：macOS 顶部 menu bar popover；iOS 全屏双语。
- 交互：`⌘+Ctrl+M` 全局唤起；剪贴板监听自动弹出。

**Language Reactor / Trancy**（Netflix/YouTube 双语字幕）
- 杀手锏：双语字幕同步滚动（视频时间轴 ↔ 字幕行）；hover 词即查；Netflix 插件可注入原文+译文字幕（外部字幕文件）。
- 视觉：黑色半透明字幕条（80% 不透明），双语 2 行（一上一下）；可调字体/位置。
- 交互：单击词保存到生词本；时间戳书签（生词卡片包含视频时间码）。

**OpenL / 火山翻译 / 彩云小译**
- OpenL：免费、支持 GPT-4 / Claude；UI 类似 DeepL 但功能浅。
- 火山引擎：字节跳动，2024 年起接入豆包大模型；强调"学术/口语/商务"风格切换。
- 彩云小译：浏览器插件 + 移动端；强调中英日韩；带"小译 AI"聊天式改写。

### 1.2 亮点挖掘（当前项目没有的杀手锏）

| # | 杀手锏 | 价值 | 实现难度 |
|---|--------|------|----------|
| 1 | **术语库 Glossary**（CSV 导入，强制术语替换） | B 端刚需 | 中（需 schema + API） |
| 2 | **风格切换**（学术/口语/商务/文学 4 档） | 让译文更"贴"使用场景 | 中（prompt template） |
| 3 | **TTS 朗读**（点击行号或 hover 整段） | 听力练习 + 校对发音 | 低（Web Speech API） |
| 4 | **不确定度可视化**（低置信度词加灰底） | 信任校准 + 优先校对 | 高（需置信度字段） |
| 5 | **修订追踪**（diff 模式：原文红删、译文绿增） | 译后编辑（Post-Editing）效率翻倍 | 中（Myers diff 已具备） |

**动效规范**
- 词 hover：背景色 fade-in 100ms `cubic-bezier(0.4, 0, 0.2, 1)`，underline 颜色从 `var(--blue-5)` → `var(--blue-7)` 200ms。
- 增量流式输出：每 token 0-2ms 滑入（transform: translateX(4px) → 0），避免"逐字蹦"导致的眩晕。
- 译文渲染完成：右侧整段 200ms 蓝色脉冲（border-left: 2px → 4px → 2px）提示新内容。

**响应式断点**
- ≥1440：左源右译 + 右侧工具栏（默认）。
- 768-1440：左右双栏但工具栏折叠到底部（底部 Tab Bar）。
- <768：单栏 Tab 切换（源/译/工具），CTA 大按钮。

**可观测指标**
- `X-Translate-Source` / `X-Translate-Target` / `X-Translate-Provider` / `X-Translate-Latency-Ms` / `X-Translate-Char-Count` / `X-Translate-Bleu`。
- 前端埋点：`ttfb` / `tttranslated`（从按下键到译文最后 1 token 渲染）/ `wordAlignmentConfidence` 分布。

**深色模式**
- 背景 `#0F1115`（Radix gray-1），源/译文字 `#E4E7EB`（gray-7），hover 高亮 `rgba(96,165,250,0.18)`（blue-5 18%），术语库色块 `rgba(250,204,21,0.12)`（yellow-5 12%）。

### 1.4 KPI 对标
- 增量延迟：< 200ms（P95, 4G 网络）
- 词级对齐准确率：> 85%
- BLEU：> 40（中英 WMT17 语料）
- 风格切换响应：< 1.5s

## 2. text（文本翻译）— Ctrl+Enter + 段落 hover + 复制

### 2.1 业界最佳实践

**DeepL Web**（桌面端体验最细腻）
- 杀手锏：编辑器即输入框，键入即流式翻译；右侧"字数 / 字符数 / 段数"统计；顶部 Language selector 是下拉但默认仅 2 个（src/tgt）。
- 视觉：白底 1.5em 行高，input 与 output 字号、字体、行距完全一致（对照感）。
- 交互：双击词即复制到剪贴板；`Ctrl+Shift+C` 复制译文；`Ctrl+Shift+V` 粘贴+翻译。

**Google Translate**（最普及）
- 杀手锏：Material 3 圆角输入框；支持文档、图片、网站、对话 4 个 Tab；右下角浮动 ★ "保存到词本"。
- 视觉：默认白底，可切深色；输入框边角 28px 圆角；按钮 Material ripple 涟漪。
- 交互：键入 → 输入框顶栏变 `?ⓘ` 信息图标（点开是"原文 vs 译文长度比"统计）；右下角"提供反馈"铅笔图标。

**微软 Translator**
- 杀手锏：多窗口（同时 3 语种并排）；PowerPoint 插件直接双语字幕嵌入。
- 视觉：紫色 #5C2D91 品牌；分段式 input 卡片。

**百度翻译**
- 杀手锏：中文段落智能断句（长文按句号/问号切，背景高亮不同色块）；词性标注（动词红色 / 名词蓝色 / 形容词绿色）。
- 视觉：浅蓝渐变输入框；右侧栏固定 4 个 Tab（词典 / 例句 / 短句 / 百科）。

**GrammarlyGO / Notion AI**（AI 改写派）
- 杀手锏：选中文本 → 浮出 4 按钮（翻译 / 改写 / 缩短 / 拉长）。
- 视觉：灰底 popover 出现在光标位置；按钮 hover 蓝色高亮。
- 交互：`/` 触发命令面板；选段后 `/translate` / `/rewrite` 弹出子菜单。

**沉浸式翻译**（输入框模式）
- 输入框 + 实时翻译；可切"按段 / 按句"分块；中英对照并排。

### 2.2 亮点挖掘

| # | 杀手锏 | 价值 |
|---|--------|------|
| 1 | **多译本对比**（DeepL/Google/Claude/自研 4 列并排） | 用户自选最佳 |
| 2 | **风格切换 + 实时预览**（4 档切换无延迟） | 写作场景刚需 |
| 3 | **修订追踪**（删除红/新增绿，类似 Word Track Changes） | 译后编辑 |
| 4 | **一键替换**（选段 → "替换"按钮 → 原文直接覆写为译文） | 翻译 → 用稿二合一 |
| 5 | **字符 / 词数 / 段数 / 句数 / 句均字数 实时统计** | 写作约束（推文 ≤ 280） |
| 6 | **智能分段**（原文按段切，译后合并相同主题） | 长文可读性 |
| 7 | **AI 改写 3 选 1**（更正式 / 更口语 / 更精炼） | 内容运营 |
| 8 | **保存为模板**（本次翻译 prompt → JSON → 复用） | 团队协作 |
| 9 | **Markdown / 富文本保留**（粗体/链接/列表不丢） | 文档场景 |
| 10 | **剪贴板监听**（复制即自动弹窗） | 零摩擦 |

### 2.3 设计稿（ASCII wireframe）

```

│  │ 用户可以单击[保存]按钮以下载文件。│         │  🔄 一键替换  ⌘+R       │
│  │                                    │         │  ✏ AI 改写 3 选 1       │
│  │ ─ 18 chars / 18 words (1 段)       │         │  📌 保存为模板           │
│  └────────────────────────────────────┘         │  ───────────────────    │
│                                                  │  历史 ⌄ (10)            │
│  ⌨ Ctrl+Enter 翻译  Esc 取消  ⌘D 复制词对  ⌘K  │  ─ 18:23 译文 1         │
└──────────────────────────────────────────────────┴─────────────────────────┘
```

**关键交互流**
1. 粘贴 5000 字 → 1.5s 内首次出现译文（流式），1.8s 全部完成。
2. 鼠标 hover 原文某段 → 右侧对应译文段蓝色脉冲 + 自动 scroll-into-view（80ms debounce + rAF）。
3. 选段 → 浮出 popover（替换/复制/改写/收藏）。
4. 切换风格 → 整体译文 1.2s 内刷新（流式）。
5. AI 改写 → 浮出 3 个候选 → 点选直接替换。

**动效规范**
- 输入字符延迟 60ms 后开始增量翻译（避免无谓请求）。
- 翻译中：输入框右下角 spinner 0.6s 线性 rotate；译文区 fade-in 200ms。
- 风格切换：旧译文 fade-out 100ms + 新译文 fade-in 200ms。
- 一键替换：原文 200ms 黄色脉冲 + 替换滑入。

**响应式断点**
- ≥1024：双栏 + 右工具栏。
- 768-1024：双栏，无工具栏（折叠为底部 sheet）。
- <768：单栏 Tab；工具栏入汉堡。

**可观测指标**
- `X-Translate-Mode: text` / `X-Translate-Style` / `X-Translate-Chars` / `X-Translate-Tokens` / `X-Translate-Model-Tokens`。
- 前端：`keyToTranslate` 间隔分布 / `styleSwitchCount` / `replaceClickCount`。

**深色模式**
- 输入框 `#18181B`（gray-2），文字 `#E4E7EB`（gray-7），hover 段 `rgba(96,165,250,0.15)`，替换高亮 `rgba(34,197,94,0.18)`（green-5 18%）。

### 2.4 KPI 对标
- 5000 字 < 3s（首次 1.5s + 完整 3s）
- 段落级 < 100ms
- 多译本对比 4 列 ≤ 6s
- AI 改写 3 候选 < 2.5s

## 3. doc（文档翻译）— DeepL Pro 标杆

### 3.1 业界最佳实践（重点 DeepL Pro）

**DeepL Pro 文档翻译**（行业绝对标杆，2024 年市占第一）
- 杀手锏：
  1. **格式完美保留**：PDF/DOCX/PPTX/HTML/XLIFF/JSON/CSV 全支持；图表/页眉页脚/字体/字号/颜色全保留。
  2. **Glossary 术语库**（CSV 导入，强制术语 100% 一致）。
  3. **Translation Memory**（TM）：记住用户/团队历史译法，重复出现时自动套用。
  4. **PDF 双语输出**：原文 + 译文双栏并排（双 PDF），可打印 / 阅读。
  5. **Bilingual DOCX**：原文+译文同段落（黄色背景标记原文，蓝色标记译文）。
- 视觉：拖拽区大圆角 12px；上传进度条蓝色 + 步骤指示（Upload → Glossary → Translate → Download）。
- 交互：上传后立即显示页数 / 词数 / 字符数估算 + 预计时间；翻译中右侧实时输出已译段数 + 进度环；支持中断 + 已译部分导出。
- 性能：100 页 PDF（≈ 25,000 词）约 45-60s；术语库 1000 条，耗时仅 +8s。
- 价格：Pro 8.74€/月、Pro Advanced 27.99€/月（含 TM + Glossary + API）。

**Google Translate 文档**（免费但能力浅）
- 杀手锏：免费；支持 PDF/DOCX/PPTX/XLSX；保留版式（但表格经常错位）。
- 视觉：Drive 集成（直接打开 Drive 文件）；翻译完成提供"在 Google Docs 打开"按钮。
- 限制：单文件 ≤ 10MB；无术语库；无 TM；无 API（仅企业 API）。

**火山引擎文档翻译**（字节跳动）
- 杀手锏：20+ 文档格式；表格内嵌文本识别（OCR 表格）；学术论文 / 合同 / 金融 3 套垂直模型。

**关键交互流**
1. 上传音频 → 进度条 → 后台 ASR + 翻译（6-8min）。
2. 完成后弹出通知；用户进入页面看到完整段卡。
3. 播放音频 → 当前段蓝色脉冲 + auto-scroll。
4. AI 摘要 / 关键词 / 待办 浮窗点击可跳转到对应时间码。
5. 导出 SRT → 下载 .srt 文件。

**动效规范**
- 当前播放段：蓝色脉冲 600ms 循环（border-left 2→4→2px）。
- Speaker 色卡 hover：饱和度 +20% + 阴影 `0 4px 12px rgba(0,0,0,0.08)`。
- 跳转时间码：滚动 300ms `cubic-bezier(0.4, 0, 0.2, 1)`，目标段淡入蓝色高亮 200ms 后淡出。
- 标记重点：黄色 ⭐ 浮入 200ms（rotate 0→360°）。

**响应式断点**
- ≥1280：左 65% 段卡 / 右 35% AI 摘要。
- 768-1280：左 60% / 右 40%。
- <768：单列（播放器 + 段卡 + 摘要入底部 Sheet）。

**可观测指标**
- `X-ASR-Engine` / `X-ASR-Lang` / `X-ASR-Speakers` / `X-Translate-Audio-Latency-Ms` / `X-Translate-Provider` / `X-Audio-Duration-Sec`。
- 前端：`asrProgress`、`playCount`、`searchCount`、`srtExportCount`、`bookmarkCount`。

**深色模式**
- 播放器 `var(--gray-2)` 背景 + 波形 `--blue-5` 80% 不透明；段卡 `--gray-1` 背景；Speaker 色块饱和度 +10%；AI 摘要卡片 `--gray-2` 背景 + 蓝色左边框 2px。

### 5.4 KPI 对标
- 1h 音频 < 10min（识别 5min + 翻译 3min + 后处理 2min）
- 说话人识别准确率 > 90%

## 6. video（视频翻译）— 剪映 / Language Reactor 对标

### 6.1 业界最佳实践

**YouTube 自动翻译字幕**（2024 引入 Gemini）
- 杀手锏：
  1. **AI 翻译字幕**：自动翻译视频字幕为 100+ 语种；可切换"自动翻译" / "原始" / "双语"。
  2. **多说话人**：自动 Speaker ID。
  3. **时间码精确到 0.1s**。
  4. **字幕烧录**（YouTube Editor 内置）。
- 视觉：底部黑色半透明字幕条；双语分上下两行；字号 24px（可调）。
- 交互：点 CC 按钮 → 字幕设置 → 翻译语种。

**剪映 AI 字幕翻译**（字节系，2024 用户量第一）
- 杀手锏：
  1. **AI 自动字幕**：上轨视频，下轨字幕；时间轴精确到帧。
  2. **多语种翻译**：一键翻译为 10+ 语种。
  3. **字幕烧录**：字幕嵌入视频（不可关闭）。
  4. **AI 配音克隆**：原声 → 目标语言（保留音色）。
  5. **关键帧预览**：视频缩略图 + 时间轴。
  6. **批量处理**：100+ 视频队列。
  7. **SRT / ASS 导出**。
- 视觉：双轨时间轴（视频 + 字幕 + 音频 3 轨）；字幕块淡蓝色；播放头红色 1px 竖线。
- 交互：拖动字幕块调整时间；单击字幕编辑文字；`Space` 播放；`J/L` 前后；`Tab` 跳转下一字幕。

**飞书妙记视频版**（视频会议转录）
- 杀手锏：实时转录 + 翻译；带"章节 + 关键词 + 摘要"。

**网易见外工作台**（网易 AI）
- 杀手锏：双语视频生成（视频中人物口型 + 配音同步翻译）；上传 1h 视频 → 1h 译版输出。

**Kapwing / VEED.io**（在线视频编辑器）
- 杀手锏：拖拽式编辑；自动字幕；翻译 + 烧录；导出 SRT/VTT/MP4。
- 价格：Kapwing Pro 24$/月；VEED Pro 24$/月。

**Descript**（播客 + 视频转录编辑）
- 杀手锏：编辑字幕 = 编辑视频（删字 → 删视频段）；"Studio Sound" 一键降噪；"Overdub" AI 克隆声音改词。
- 视觉：Word 文档式时间轴（每词 1 行，可编辑）。

**Language Reactor**（Netflix 插件 + 通用）
- 杀手锏：双语字幕同步滚动（YouTube / Netflix / 自有视频）；hover 词取词；生词本。
- 视觉：黑色字幕条；原译双行；可调字体/位置/颜色。

## 对 Office AI 项目优先级建议

### ROI 矩阵（影响 × 实现成本）

| 子模式 | 当前实现度 | 行业差距 | 用户呼声（推算） | ROI 排序 | 推荐交付窗口 |
|--------|-----------|---------|------------------|----------|--------------|
| **text** | 中（已能用） | 中（多译本/AI 改写缺） | 高（最高频入口） | 🥇 #1 | **下周**（快速胜利） |
| **realtime** | 高（最强） | 中（术语库/风格切换缺） | 高 | 🥈 #2 | **下周**（增值点） |
| **doc** | 中（基本可用） | 高（Glossary/TM/版式保留） | 高（B 端） | 🥉 #3 | **本周/下周**（B 端刚需） |
| **image** | 中（OCR+翻译） | 中（inpainting/批量缺） | 中 | #4 | 2-3 周后 |
| **audio** | 低（仅占位） | 极大（全栈缺口） | 中 | #5 | 2-4 周后 |
| **video** | 低（仅占位） | 极大（FFmpeg/字幕烧录） | 中-低 | #6 | 1-2 月后 |

### 推荐交付计划

**Week 1（快速胜利 - 8 个核心增量）**
1. **text：多译本对比 2-4 列**（一次请求 2-4 模型）— 投入 1 人天
2. **text：AI 改写 3 候选**（更正式/口语/精炼）— 1 人天
3. **text：修订追踪 diff 模式**（用现有 Myers）— 0.5 人天
4. **realtime：术语库 CSV 导入 + 强制着色**— 2 人天
5. **realtime：风格切换（学术/口语/商务/文学 4 档）**— 1.5 人天
6. **realtime：TTS 朗读（Web Speech API 零依赖）**— 0.5 人天
7. **realtime：翻译历史栈（Undo/Redo `Alt+Z/Shift+Z`）**— 0.5 人天
8. **doc：Glossary CSV 导入 + 强制替换**— 2 人天

**Week 2（B 端突破）**
9. **doc：Translation Memory（JSON 持久化 + 复用）**— 3 人天
10. **doc：双语 DOCX 输出**（用 docx 库）— 2 人天
11. **doc：进度环 + 中断 + 局部导出**— 1.5 人天
12. **image：原图 + 译文 双视图切换 + 区域选择**— 2 人天
13. **image：批量翻译队列（10+ 图）**— 2 人天
14. **image：词典卡片（点词即查）**— 1.5 人天

**Week 3-4（多媒体扩展）**
15. **audio：说话人识别 + 彩色卡片**（pyannote.audio）— 4 人天
16. **audio：AI 摘要 / 关键词 / 待办**（LLM 抽取）— 2 人天
17. **audio：SRT/VTT 导出**— 1 人天
18. **audio：段同步滚动（timeupdate）**— 1.5 人天

**Month 2（视频旗舰）**
19. **video：自动字幕 + 翻译**— 5 人天
20. **video：字幕烧录（FFmpeg）**— 3 人天
21. **video：关键帧缩略图 + 时间轴**— 2 人天
22. **video：说话人识别**（复用 audio）— 2 人天
23. **video：AI 配音（接入火山/字节 MegaTTS）**— 7 人天

### 关键设计原则
1. **realtime/text 优先**：最高频入口 → 先打磨细节（动效、键盘、可观测）
2. **doc 主打 B 端**：Glossary + TM + 双语输出 = 行业入场券
3. **image 渐进式**：先做"区域选择 + 双视图"，inpainting 后期接自研模型
4. **audio/video 共享底层**：Speaker ID / 段同步 / 导出 三件套抽公共模块
5. **可观测先行**：每个模式上线即带 `X-Translate-*` 响应头 + 前端埋点
6. **动效统一**：所有 hover 100ms、所有切换 200ms、所有 pulse 600ms（Material easing）
7. **深色模式默认**：参考 Radix 12 级灰阶 + 品牌蓝 `--blue-7` / 暗模式 `--blue-5`

### 必须避坑
- **不要 6 个子模式并行**：按 ROI 滚动交付，每模式 1-2 周闭环
- **不要在 1 周内做 AI 配音 / 唇形同步**：技术风险极高，且非核心
- **不要重复造 OCR / ASR 引擎**：直接接百度 / 字节 / OpenAI
- **不要忽视键盘流**：译员 / 字幕组用户键盘效率 = 留存
- **不要忽视可观测**：每个请求带 X-Translate-* headers，便于灰度对比
